## Featured Projects

### 🤖 [LangGraph Personal Assistant](https://github.com/slnnzmtl/langgraph-personal-assistant)

A Telegram-based personal assistant built as a pnpm workspace with LangGraph and a reusable supervisor framework. The system routes conversations to specialized runtime agents for finance, Obsidian knowledge management, configuration, and custom user-defined workflows.

- Supervisor-based multi-agent architecture with isolated execution contexts
- Gemini-powered agent workflows with configurable model policies
- Finance automation using Supabase MCP and Wise API integrations
- Obsidian vault read/write workflows and reusable XML skills
- Cron-triggered tasks and Telegram interaction
- LangSmith tracing, Docker Compose deployment, Vitest tests, and Playwright end-to-end tests
